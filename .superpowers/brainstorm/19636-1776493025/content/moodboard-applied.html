What actually changes
01

Gradient glow backgrounds

Every screen gets a radial gradient "light bloom" behind the hero — green on scan, amber on recipes. This is the single biggest visual change. Uses LinearGradient or CSS border-radius hack, no extra library.

02

Organic food circles

Decorative colored orbs (orange, yellow-green) in the top-right corner of the scan home hero. Pure View + borderRadius + gradient. Gives it the fruit app personality without actual images.

03

Much bigger hero type

Hero headline goes from 32px → 46px, tighter letter spacing, with an italic ghost second line (rgba white). System SF Pro at this size looks genuinely editorial.

04

Tinted icon backgrounds per mode

Receipt = green tint, Barcode = amber tint, Photo = blue tint. Right now all three icons have the same flat green dim. Unique tints add visual rhythm and personality instantly.

05

Onboarding gets a visual hero

Giant ghost number (02, 03…) as a typographic background element + an emoji circle with glow ring. Turns the empty text panels into something you actually pause on.

06

Recipe cards get a real visual

Cards become full-bleed with a gradient food-themed background + large food emoji as hero, then gradient overlay with recipe info. Like a real recipe app, not a list.

07

Colored macro chips

Protein = blue tint, Carbs = amber tint, Fat = yellow tint, Calories = green tint. The theme already defines these colors but they're not being used on the cards. This is pure color.

08

Stronger animations

Current stagger is 8px translateY — barely visible. New: spring physics, 24px translateY, scale from 0.97→1, entrance blur. The How We Feel app feels alive because every element bounces in.
